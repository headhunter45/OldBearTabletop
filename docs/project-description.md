# OldBearRodeo

OldBearRodeo is a lightweight, mobile-friendly virtual tabletop (VTT) for hosting tabletop roleplaying sessions without mandatory sign-ins. It provides browser-local asset storage, real-time room synchronization, a canvas-based tactical map, token and combat tools, voice chat, and D&D Beyond character integration.

## Highlights

- HTML5 Canvas map engine with pan, zoom, pinch-to-zoom, grid overlays, snapping, fog of war, pointers, markers, and movement measurement.
- WebSocket room synchronization with WebRTC voice communication and server relay support.
- Local browser storage for maps, tokens, audio, character sheets, and portable session backups.
- Token ownership, health bars, status conditions, movement speed tracking, and a movement ruler.
- Dice roller with advantage/disadvantage support and a synchronized initiative tracker.
- D&D Beyond character import for public character sheets, including HP, speed, ability scores, skills, spells, and avatar data.
- GM soundboard controls for synthesized effects and uploaded audio tracks.
- Responsive navigation designed for desktop and mobile play.

## Technology

- TypeScript monorepo managed with npm workspaces.
- React and Vite client.
- Node.js and WebSocket server.
- HTML5 Canvas rendering.
- WebRTC voice communication.
- IndexedDB browser storage.
- PostgreSQL and Docker Compose deployment support.
